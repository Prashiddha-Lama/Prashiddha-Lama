## What I've built

**[KHDA Dubai School Performance Analytics](https://github.com/Prashiddha-Lama/Dubai-School-rating-analysis)**
Went through performance data for 428 Dubai schools to see what actually separates the top performers. Built a Decision Tree classifier that hit 88% accuracy and used K-Means to find natural groupings in the data, then put it all in a Power BI dashboard so it's actually readable.

**[CVD Risk Prediction](https://github.com/Prashiddha-Lama/predictive-analytics-heart-disease)**
A logistic regression model for cardiovascular risk. The dataset was heavily imbalanced, so I used Borderline-SMOTE to correct it before training. Final AUC came out to 0.816, ahead of the Framingham Risk Score, which is the usual benchmark for this kind of model.
